# Add module

1. If not already clear, ask what the new module is for and what it should be named.
2. Create the directory.
3. Write `<module>/CLAUDE.md` following the structure used by the other scoped CLAUDE.md files in this repo: what belongs here, what doesn't (and where that does belong instead), and a non-obvious-patterns section.
4. Add a row for the new directory to the "Directory map" table in the root `CLAUDE.md`.
5. Write the module's CLAUDE.md in the same turn as the directory — before writing any code into it, not as a follow-up.
